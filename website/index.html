05 / BEFORE YOU SETTLE IN

Good questions.
Straight answers.

Ask us something else ↗
What exactly is Gamekins?+

A desktop launcher that brings your supported Epic Games, Steam, GOG, and local games into one library. Organize collections, manage supported Epic downloads, and launch into your next game from one place.

Do I need to buy my games again?+

No. Gamekins helps organize games you already own. Games and licenses come from their respective stores. Online libraries require the corresponding provider account, and Steam/GOG features rely on their official clients.

What’s different about the Microsoft Store edition?+

It keeps library and launcher tools, while opening third-party catalogs and purchases in your browser. Unclassified catalog media and native chat are disabled. Provider content and family controls remain with the provider. A standard Windows x64 desktop is required; S mode is unsupported.

Does every game work on every platform?+

Compatibility depends on the game, operating system, provider, and required clients. Linux currently focuses on Steam handoffs and native local games. An Epic compatibility runner is not bundled; GOG on Linux uses manual downloads and local-game import.

Is it really open source?+

Yes. Gamekins is MIT-licensed. You can read the code, build it yourself, report an issue, or contribute on GitHub. This version does not include games, cloud saves, achievements, or native Steam/GOG downloads.
